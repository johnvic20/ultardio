# Ultardio site

Static site (one file: index.html, no build step).

## Deploy
1. Create a GitHub repo and upload index.html (and this README) to the root.
2. Go to vercel.com > Add New > Project > import the repo.
3. Framework Preset: Other. Leave build command/output empty. Deploy.

Live price data loads from the DexScreener API in the browser, so it only works on the hosted site (not from a file opened locally).
